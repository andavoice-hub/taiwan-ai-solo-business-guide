# 台灣 AI（人工智慧）一人公司變現指南

想靠 AI 做一人事業，可以先從這 30 條做法挑一條。每條都寫了成本、做法、要看的結果和風險。不保證收入。

## 目錄

- [30 條指南](指南.md)：按主題閱讀。
- [網頁版](site/index.html)：手機可讀，也能搜尋。
- [授權說明](LICENSE)：可非商用分享，須標示來源。

## 怎麼用這份指南

**一句話懂：**先挑一件做得到的事，做完再看結果。

1. 先選自己正在做的類別，只挑一條行動。
2. 點開來源核對。資料查證於 2026-10-18，價格、規則與法規可能改變。
3. 先小規模試做，再記下結果。記錄數字不代表一定有收入。

**你現在可以做的一件事：**打開[指南](指南.md)，挑一條適合自己的做法。

「官方」是官方資料。「法規」是法律或主管機關資料。「推論」是我們根據來源提出的做法，效果還沒驗證。自有設備和工時是估算。
