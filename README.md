# 台灣 AI 一人公司變現指南

100 條計畫的 **30 條精華版**：每類 3 條，逐條附工具或法規來源、成本、照做步驟、可衡量結果與風險。不保證收入。

## 怎麼用這份指南

1. 先選自己正在做的類別，只挑一條行動。
2. 點開該條原始來源，查證日期是 2026-10-18；平台價格、規則與法規可能改變，實施前重新核對。
3. 照步驟做小規模測試，以條目中的指標記錄結果。指標是量測方法，不是收益承諾。

每條固定標示結論、對象、成本、可衡量結果、操作、證據、來源及風險。「官方」是官方功能、價格或政策，「法規」是法律與主管機關資料，「推論」是依來源提出的行動假設，效果尚未驗證。工具價格直接引官方價目；自有設備與工時估算另有註明。內容原始資料在 `guide_data.py`；執行 `python build_guide.py` 重建 Markdown 與離線網頁，再執行 `python verify.py` 檢查內容門檻。

本指南只參考 [HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)「條目列成本、收益、證據與來源」的呈現結構，沒有轉載其內容。原專案正文採 [CC BY 4.0](https://github.com/eternity4719/HowToLiveBetter/blob/main/LICENSE)，程式採 [MIT](https://github.com/eternity4719/HowToLiveBetter/blob/main/LICENSE-CODE)。本指南原創內容沿用 [CC BY-NC 4.0](LICENSE)，非商用可轉載，須標示安達與授權連結；其他用途請洽 https://anda.biz。因含非商用限制，本指南是公開閱讀資料，**不是 OSI 定義的開源軟體**。
